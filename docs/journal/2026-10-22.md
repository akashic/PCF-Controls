**Discussion & decisions:**
- **Fluent:** declare 9.46.2, the highest version Microsoft Learn documents as supported (#3's research), rather than the 9.68.0 `pac` generates. Confirmed in the grid during the spike.
- **Config storage:** the spike found that JSON environment variables cap at 2,000 characters (about 10 rules). The developer chose one JSON web resource per table, shipped in the project solution (ADR-0004), so the brief's environment variable and `ruleSets` design is superseded.
- **Styling technique** (from the spike, worked out with screenshots and console dumps):
  - the grid theme overrides cell backgrounds with `!important`, so tints are painted as a `background-image` layer, which keeps hover and selection visible;
  - colour and bold need the control to draw simple cells itself, never the primary name (that would lose the record link);
  - the grid waits for `fireEvent`, so config loads first;
  - option colours sit in `attributeDescriptor.OptionSet[].Color`.
  - A RAG colour demo proved the metadata → shared colours → tint/pill path before the engine was built.
- **#10 approvals:** the developer approved `ajv` as a dev-only validator, plus three assumptions: `priority` defaults to 0, `alias.column` names are allowed, and choice values stay numeric.
- **Namespace:** asked about the `WB.` in `wb_WB.GridFormatter`. The namespace can't be removed, so the developer changed it to `Controls`; logical names are now `wb_Controls.*` (ADR-0003 amendment). Done before any WB environment had the controls.
- **Publisher:** created by hand in the WB dev tenant with the canonical values; UAT and prod have no `wb` publisher, and `wb` / `WilliamBuck` is final (#2 closed).
- **Agent coordination:** parallel agents were kept off each other's files; shared groundwork (GridFormatter's Jest setup, #22) went in first; and #12 took the condition evaluator as an injected parameter so it didn't depend on #11.
